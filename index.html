  • Round-robin format: each pair plays every other pair within their assigned group.

🏸 5. Scoring System & Match Format

All matches will follow the 21-point, Best-of-3 Sets format with No Deuce.

21 Points per Set
Best of 3 Match Format
No Deuce Scoring Rule

Official Scoring Rules

  • Ang unang team na maka-reach ng 21 points ang winner ng set.
  • Kapag umabot ang score sa 20–20, ang unang team na maka-score ng 21st point ang declared winner ng set.
  • Walang deuce, score extension, o two-point advantage requirement.
  • Kapag nanalo ang isang team sa first and second sets, automatic match winner na sila with a 2–0 result.
  • Kapag parehong may tig-isang set na panalo (1–1), magkakaroon ng third and deciding set.
  • The third set will also follow the 21-point scoring system with no deuce.
  • Ang team na unang manalo ng dalawang sets ang official match winner.

Sample 1 — Straight Sets (2–0)

Team A wins both the first and second sets.

Set Team A Team B Winner
1st Set 21 18 Team A
2nd Set 21 20 Team A
3rd Set — — Not Required
Sets Won 2 0 Team A
🏆 MATCH WINNER: TEAM A (2–0)

Dahil nanalo ang Team A sa unang dalawang sets, hindi na kailangan ng third set.

Sample 2 — Deciding Set (2–1)

Both teams win one set each, requiring a third and deciding set.

Set Team A Team B Winner
1st Set 21 20 Team A
2nd Set 20 21 Team B
3rd Set 18 21 Team B
Sets Won 1 2 Team B
🏆 MATCH WINNER: TEAM B (2–1)

Dahil parehong may tig-isang set na panalo ang dalawang teams, ang third set ang nag-determine ng match winner.

⚠️ IMPORTANT SCORING REMINDER

Maximum of 21 points per set. Kapag umabot sa 20–20, next point wins!

NO DEUCE. NO EXTENSION. NO TWO-POINT ADVANTAGE.

This rule applies to all three sets.

⚖️ 6. Tie-Breaking Rules

Kapag may pairs na pareho ang win-loss record, susundin ang criteria in order:

Priority 1 — Total Wins

Kung sino ang may pinakamaraming wins, siya ang mas mataas sa ranking.

Priority 2 — Point Difference

Formula: Total Points Scored − Total Points Conceded

Team Wins Losses Difference
Team A — Rank 1 2 1 +15
Team B — Rank 2 2 1 +8
Team C — Rank 3 2 1 −3

Ang may pinakamataas na point difference ang mangunguna.

Priority 3 — Total Points Scored

Kapag pareho pa rin ang point difference, ang pair na may highest total points scored ang aangat.

Priority 4 — Additional Head-to-Head Matches

  • Two-way tie: additional head-to-head match.
  • Three-way tie: additional matches among the three tied pairs.
  • Match Controller ang magse-set at magre-record ng additional matches to determine final rankings.
  • Kung unresolved pa rin, ang organizing committee ang magde-determine ng next course of action.
